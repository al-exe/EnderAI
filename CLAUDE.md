# EnderAI backend — agent rules

## Documentation sync (single canonical doc home)
- This repo is the **single home for ALL docs** — planning, design, reference, **including frontend-related docs**. No docs live in the frontend repo or in local-only folders.
- Write them under `docs/` — use `docs/planning/` for planning docs.
- After creating or editing **any** doc, immediately `git add` it, commit, and `git push origin main` so docs stay in sync across Alex's two dev machines.
- This direct commit + push is intentional for **docs only** and overrides the PR-first workflow for these files. It does **not** apply to code changes — code still goes through a branch + PR.
