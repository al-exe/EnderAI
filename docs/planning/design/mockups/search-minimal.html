YOU how do we handle stripe tax for new subscribers?
TF

On signup we attach automatic_tax: { enabled: true } to every subscription. For business accounts we additionally pass tax_id_collection so customers can input a VAT ID at checkout§1.

Edge case: EU customers with no VAT are blocked at confirm — our fallback switches them to the B2C plan§3. The full rationale (and why we didn't build a custom tax engine) is in the tax-engine decision note§5.
