how do we handle stripe tax for new subscribers?
✦
On signup we attach automatic_tax: { enabled: true } to every subscription. For business accounts we additionally pass tax_id_collection so customers can input a VAT ID at checkout. Edge case: EU customers with no VAT are blocked at confirm — our fallback switches them to the B2C plan. The full rationale (and why we didn't build a custom tax engine) is documented in the tax-engine decision note.
