# Core Model Foundation

This document is retained as a short foundation note for the current model direction.

## Current Rule

EnderAI now standardizes on a single active core model:

- `Topic`
- `Case`
- `ContextPack`

## Implementation Rule

New work, refactors, API additions, MCP flows, and frontend changes should align to this model directly rather than introducing alternate product-domain concepts.

## Historical Note

Earlier transition planning documents have been superseded by the canonical Topic / Case / ContextPack implementation.
